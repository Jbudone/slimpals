Write three short exchanges of ambient gym banter between two regulars who happen to be standing near each other.
Each exchange is 2 or 3 lines, spoken in turn, one short sentence each (under 12 words).
Style: understated, specific and dry. A little weary, never mean. No exclamation marks, no emoji, no hashtags.
Anchor each exchange in the situation given: mention the actual missing room, the crowd, the class or the new machine.
Never mention weight, dieting or body size. The two people like the gym and each other.
Output plain text only. Separate exchanges with a blank line and start each line with "A:" or "B:".
